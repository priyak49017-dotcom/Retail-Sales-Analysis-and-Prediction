Retail Sales Analysis and Prediction
📌 Project Overview
This project analyzes retail sales data to uncover business insights and predict sales using Machine Learning. The workflow includes data cleaning, exploratory data analysis (EDA), data visualization, and sales forecasting with Linear Regression.
🎯 Objectives
Clean and preprocess retail sales data
Analyze customer demographics and purchasing behavior
Visualize sales trends and product performance
Build a predictive model for sales forecasting
Generate actionable business insights
